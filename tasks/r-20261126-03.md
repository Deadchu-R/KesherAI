For each component below, say what it is written in now (TypeScript unless noted), whether it is CPU-, memory-, I/O- or wait-bound, and whether another language would make it clearly faster or lighter (Rust via napi-rs or a sidecar, Go, C++, Zig, Python, WebAssembly, GPU shaders), with the expected gain, the cost (build, Windows, maintenance, AI coding agents' skill in that language) and examples from similar open-source apps:

- packages/core: the Fastify server, task inbox and agents' runner, log reader and search, privacy/leak guard (regex scans of diffs and prompts), project indexing, git worktrees, terminals (node-pty), downloads
- packages/providers (HTTP/SSE streaming to model servers), packages/agent (the agent loop and tools), packages/downloads (big model files: hashing, resume)
- engines KesherAI runs: llama.cpp (C++/CUDA), ComfyUI (Python), stable-diffusion.cpp, Whisper/F5-TTS speech, CPU watchdog model
- plugins: image, sound, video and 3D editors (heavy pixel/audio/mesh work in the browser: Canvas/WebGL/WebGPU/WASM)

End with a ranked shortlist: the 3-5 changes with the best speed/RAM gain per hour of work, and what to measure first to confirm each. Cite sources; mark anything uncertain.
