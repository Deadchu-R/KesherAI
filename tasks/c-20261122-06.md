## Goal
KesherAI connects several computers (main PC with a 24 GB GPU, a laptop, a phone). Research how distributed local AI tools split work (exo, llama.cpp RPC, Petals, distributed ComfyUI, Ollama clusters, LocalAI federation): per-chat device choice, routing by hardware, splitting a model across machines vs routing whole jobs, the laptop never gets heavy work, failure handling, security.
KesherAI context: open-source local-first AI desktop app (Electron + React web UI, Node server, local models via llama.cpp / sd.cpp / ComfyUI), Hebrew + English, used by a game developer on a home PC and from his phone. Research end to end how the best tools do it (official docs, changelogs, repos, reviews from the last 12 months), then what KesherAI should build first.
