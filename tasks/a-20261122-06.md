## Goal
Roee (2026-11-22): three providers carry the hub's traffic and take over from each other, so a limit or outage at one never stops KesherAI. Today only the Cloudflare hub exists; packages/core/src/relay.ts is the base for more (RelayProvider, RelayKind; sealed envelopes already carry unique ids and the receiver drops repeats, ReplayGuard in packages/shared/src/hub-crypto.ts).
Build a transport interface in packages/shared (connect, publish(envelope), onEnvelope, close, health) with two adapters using the providers' plain WebSocket/REST protocols (no new npm dependency; fetch + WebSocket): Ably (free: 6M messages a month, 200 connections, no card) and Supabase Realtime broadcast (free: 2M messages a month, 200 connections). Channel per pair: a name derived from the pair's shared key (HKDF, never the device id in clear); only sealed envelopes go through (the providers see ciphertext only). Keys: Settings › Kesher Cloud › 'Backup relays': Ably API key; Supabase project URL + anon key — stored like the other keys (never logged, never sent to the hub); the phone gets them inside the sealed pairing data, not in plain text. Add RelayKind 'ably' | 'supabase' to relay.ts.
