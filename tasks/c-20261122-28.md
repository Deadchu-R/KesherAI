## Goal
Always about KesherAI and its usability for Roee. Roee wants KesherAI to set itself up from users' prompts and requests: "I make Unreal games and want a Hebrew voice assistant" → KesherAI picks and downloads the right local models for the PC's hardware, installs the engine plugins, turns on the right features and agents, connects free cloud providers (asking for keys), and explains what it did — with the user's approval before downloads and installs, and fully undoable.
Research end to end how others do onboarding and self-configuration by intent: LM Studio / Ollama / Jan / LobeHub / Msty first-run and model recommendations by hardware, ComfyUI Manager (missing-node install), Pinokio one-click installers, Cursor/Windsurf/Claude Code setup and project rules, VS Code profiles and "setup from a prompt" features, Home Assistant/iOS Shortcuts-style "do it for me" setups, Unity Hub / Epic launcher module picks, and any "agent configures the app" products. Also: how to describe KesherAI's settings, features, models and plugins as a machine-readable capability catalog an agent can plan against; safety (approve every download/install, quota/size limits, no payments, rollback/snapshot of settings); and how it works from the phone (remote) too.
To look at KesherAI's code (settings, models catalog, downloads, plugins, providers), use your file tools or simple read-only commands.
