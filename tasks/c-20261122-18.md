## Goal
Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Determine how KesherAI can reliably inspect and extract actor hierarchies, transforms, and mesh references from Unreal Engine 5.x levels (.umap) while the heavyweight Unreal Editor GUI is closed.

## Read first
- docs/WORK_LIST.md (lines 17, 27, 204, 269)

## Acceptance
- Deep technical evaluation comparing three parsing avenues:
  1. Direct binary parsing of `.umap` package summaries and Zen Loader asset registries (`AssetRegistry.bin`) via open-source TypeScript/C++ libraries (e.g., UAssetAPI).
  2. Headless invocation of Unreal commandlets (`UnrealEditor-Cmd.exe Project.uproject -run=UKesherBridgeCommandlet -stdout -unattended`).
  3. Pre-indexing levels during editor session shutdowns into lightweight JSON cache files.
- Explanation of why previous headless plugin reads failed on AutoShooter / TestProj (empty level list bug) and exact recovery steps.
- Performance and memory benchmarks: RAM footprint and startup latency comparison between running `UnrealEditor-Cmd.exe` vs reading cached asset registries.
