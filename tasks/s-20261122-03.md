## Goal
A preview picture per level/scene in KesherAI's scene list. Unreal: a .umap may hold a saved thumbnail in its package's thumbnail table (FPackageFileSummary.ThumbnailTableOffset → FObjectThumbnail: width, height, compressed image bytes); extract it when present (UE 4.27 and 5.x), serve it as an image from a new GET route (/api/unreal/level-preview?project=&level=), cached under the project's KesherAI data dir (not in the game project). Unity has no stored scene thumbnail: when the Unity bridge is connected and that scene is open, capture the Scene/Game camera to a 320px PNG through the existing bridge screenshot path and cache it per scene path+mtime; otherwise none. Route GET /api/unity/scene-preview. Both return 404 when there is no picture (the UI then shows the stats only). Validate project/level params against the known project list (no path traversal). Rules: research first how Unity Hub, Unreal Content Browser/"Open Level" and tools like UnityYAMLMerge / UAssetAPI / CUE4Parse read these files (write 5–10 lines into docs/RESEARCH_LOG.md), then build. Read-only on the game project (never write into it). Readable, documented (JSDoc) code; node:test tests next to the code with small fixture files you create; Hebrew+English texts with L(he,en); 390px phone layout; works from the phone through the hub (no PC-only APIs in the web part). Update docs/WORK_LIST.md section "Scene previews" (create it).
