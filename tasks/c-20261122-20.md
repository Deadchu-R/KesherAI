## Goal
Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Design a real-time GPU VRAM watchdog and memory coordinator that prevents crashes and power surges by arbitrating VRAM allocation between llama.cpp, ComfyUI, and game engines entering Play mode.

## Acceptance
- Real-time VRAM polling mechanism evaluated for Windows 11 (NVML via node bindings vs `nvidia-smi` daemon vs DirectX DXGI adapter query).
- Play-mode standby protocol defined: detecting Unity/Unreal Play mode events via WebSocket bridges, executing `llama_state_save_file` in llama.cpp, unloading VRAM to system RAM within 500 ms, and restoring state upon Play exit.
- Multi-engine arbitration rules established: priority hierarchy between Chat LLM, Vision Router (2B), ComfyUI diffusion jobs, and Game Engine viewports.
- Power surge and watchdog protections documented: maximum concurrent heavy jobs (strictly 1 heavy job), thermal threshold limits, and crash recovery logging.

## Out of scope
Do not alter Windows GPU drivers or install binary packages.

## Report
Write the arbitration algorithm, latency expectations, NVML/DXGI query methods, and state save/restore commands to docs/research/c-20261122-20.md.
