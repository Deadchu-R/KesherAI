## Goal
Convert a copy of the KesherAI Unreal plugin so it compiles and works on Unreal 4.27 (project "ForMigration").

1. Copy every file of `integrations/unreal/KesherAIBridge/` into `integrations/unreal/KesherAIBridge-ue4.27/` (a new folder). Do not change `integrations/unreal/KesherAIBridge/`: the original stays as it is.
2. In the copy only, change what Unreal 4.27 needs: API names and headers that differ, removed or renamed classes, the build files (the .uplugin's EngineVersion, Build.cs module names). Keep the behaviour; leave out a feature that cannot exist on Unreal 4.27, with a comment saying so.
3. Write `integrations/unreal/KesherAIBridge-ue4.27/CONVERTED.md`: the target version, what was changed, what was left out, and that it was converted by AI and may not work well.

## Acceptance
Only files under integrations/unreal/KesherAIBridge-ue4.27/ are added or changed.
integrations/unreal/KesherAIBridge-ue4.27/CONVERTED.md lists the changes and the warning.
No new dependencies, no downloads.
