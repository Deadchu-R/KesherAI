## Goal
Research only (no code). Under 1,500 words. Public sources only.
KesherAI is a desktop AI app whose chats can use a browser, the computer, files and code, with local models (Qwen 27B / 9B class) and cloud models. The owner wants its chats to feel like Claude, ChatGPT agent mode, Gemini agent mode and Manus.
Find the user-visible behaviours that make those agent chats feel capable: a live task list, folded steps, check-back timers, multiple-choice questions to the user, asking before an action, handing control back to the user mid-task, progress notifications to the phone, side panels for outputs, parallel helpers, memory, scheduled tasks, files delivered into the chat, resuming after a restart, background commands. For each: how it looks, when it triggers, what the user can do. Then the 10 things weaker local models most often get wrong in such loops and known fixes (smaller tool lists, plan first, a checking step, retries, short answers).
Include a short 'Language and weight' part and end with '## Tasks': 8-12 concrete tasks (S/M/L) for KesherAI, skipping ones it already has (task list, timers, scheduled tasks, files into chat, past-chat search, background commands).
