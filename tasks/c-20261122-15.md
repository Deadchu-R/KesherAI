## Goal
Roee wants KesherAI's computer control to be visible the way Claude's computer use is: an orange frame around the screen while the model drives, the model's own mouse cursor drawn on screen, and short captions of each step — also inside tools and game engines (Unity Editor, Unreal Editor, Blender, Photoshop-like apps). Two more parts:
1. Point-to-confirm: the model hovers over an object (a mesh in the viewport, a button, a node) and a small speech bubble above it asks "Is this the object you meant?" with Yes / No.
2. Co-developer mode: while Roee works, KesherAI watches the screen in real time, understands the context (which app, which asset, what he is doing) and offers suggestions in a bubble he can accept or dismiss — also in general, not only in engines.
It must be very light on the PC, because it runs next to heavy work (Unreal builds, local models). If the PC has a second graphics card, the overlay/vision work should be able to run on it, each card doing its own jobs (Roee has one card now; design for two).

Research end to end, with sources: Claude computer use / Claude for Chrome (orange frame, cursor, step captions), OpenAI Operator/Agent, Google Project Mariner / Gemini computer use, Microsoft Copilot Vision and Recall, Windows Click to Do, Rewind/Limitless, Screenpipe, UI-TARS desktop, Cursor/Copilot "next edit" style inline suggestions, Unity Muse/AI assistant and Unreal AI tools that point at objects, game-engine editor overlays (Unity SceneView/Unreal viewport hit-testing through the KesherAI Unity package and Unreal plugin, so the bubble can sit on the real object without screen-vision guesses), accessibility trees (Windows UI Automation) vs screenshots, transparent click-through overlay windows on Windows (Electron/WinUI layered windows, DXGI desktop duplication cost), low-cost change detection (only look when the screen changes), small local vision models for screen understanding (sizes, VRAM, speed), and pinning work to a chosen GPU on Windows (DirectML/Vulkan/CUDA device selection, Windows graphics preference per app).
Has anyone shipped all of this together? What is missing that KesherAI can do first?
To look at KesherAI's code (packages/core computer control, apps/desktop, integrations/unreal, the Unity package), use your file tools or simple read-only commands.
