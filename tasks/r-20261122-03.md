## Goal
Roee wants KesherAI's computer control to be visible like Claude's: while a computer task runs (packages/core/src/control-task.ts, route /api/control/tasks), show on the PC screen:
1. A thin orange frame around the edge of the screen being controlled.
2. The model's own cursor (a small orange pointer) moving smoothly to where each step clicks or types.
3. A short caption near the bottom of the screen with the current step ("Clicking Install", "Typing in Search").
4. A "Take over" button in the caption that stops the task at once (calls POST /api/control/tasks/:id/stop).

How: a transparent, always-on-top, click-through Electron window per display in apps/desktop (only the caption is clickable; use setIgnoreMouseEvents(true, {forward:true}) and toggle over the caption), fed by the existing control task steps (subscribe in-process or poll /api/control/live). It must be light: no capture, no animation when no task runs, the window is hidden when idle. Respect multiple monitors (draw on the display of the window being controlled). The same step line already shows on the phone in #/watch; keep that in sync.
Put the overlay state logic (what to draw for a step) in a pure module with unit tests; the Electron part stays thin. Read docs/research/c-20261122-15.md first (sections on visible control) and follow it where it fits.
Write a short note in docs/WORK_LIST.md (Morning 22.11 section) marking this done, and say what is left (point-to-confirm bubble, proactive suggestions).
