## Goal
Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Research how to parse Figma REST API layout trees and design tokens, translating them automatically into native Unreal Engine UMG Widget Blueprints and Unity UI Toolkit (UXML/USS) structures.

## Acceptance
- Layout mapping matrix defined: Figma Auto-Layout flexbox rules (direction, padding, spacing, alignment) mapped to Unity UI Toolkit Flexbox (USS) and Unreal UMG Canvas/Horizontal/Vertical/Grid panels.
- Design token extraction specified: typography, color palettes, border radius, and 9-slice sprite slice parameters conforming to W3C Design Token standards.
- Asset export pipeline: fetching vector SVGs and raster textures via Figma REST API, saving into project asset folders (`Assets/UI` or `Content/UI`), and configuring import settings (Sprite 2D / Texture2D).
- Offline bridge: generating deterministic C# or Python scripts that construct the UI hierarchy headlessly without opening the engine editor.

## Out of scope
Do not make live calls to Figma APIs or generate binary `.uasset` files.

## Report
