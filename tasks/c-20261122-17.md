Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Design an automated, headless night build pipeline for Unity and Unreal projects that executes an unattended smoke test, captures health telemetry, and delivers a morning scorecard to the paired phone.

## Acceptance
- Comprehensive CLI invocation patterns documented for headless compilation: Unity (`-batchmode -nographics -executeMethod`) and Unreal Engine (`RunUAT.bat BuildCookRun -noclient -nodebuginfo`).
- Headless smoke-test architecture specified: running the built executable with a timeout guard (60 s), detecting crashes (exit codes, minidumps), validating asset loading via log streams, and capturing a frame buffer screenshot.
- Scorecard data schema defined: build duration, binary size deltas, compiler warnings/errors, peak RAM/VRAM usage, and smoke-test status.
- Sealed phone notification delivery flow detailed via Kesher Cloud hub push notifications (`hub-protocol.ts`).
