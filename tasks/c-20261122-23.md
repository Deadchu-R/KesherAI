## Acceptance
- Cloudflare API v4 integration blueprint: authenticating via a user-generated scoped API token (`Workers Scripts:Edit`, `Custom Domains:Edit`, `Secret:Edit`).
- Automated deployment sequence specified: creating the Worker script from precompiled JS bundle, configuring custom route/domain, setting environment secrets (`ALLOWED_EMAIL`, `GOOGLE_CLIENT_ID`), and validating health check `/api/health`.
- Analysis of industry reference patterns: Cloudflare "Deploy to Workers" button, Coolify onboarding, and Vercel CLI deploy flow.
- Fallback zero-config alternative researched: local Tailscale Funnel / Cloudflare Tunnel provisioning for users without custom domains.

## Out of scope
Do not deploy actual Cloudflare workers or make external API requests.
