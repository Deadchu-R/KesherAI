## Goal
Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Architect an autonomous playtesting agent inside KesherAI that boots a Unity or Unreal scene in Play mode, navigates the environment, detects bugs/hangs, and outputs structured bug receipts with screenshots.

## Acceptance
- Input injection architecture detailed for both engines: Unity Input System (`InputTestFixture` / virtual device feeding) and Unreal Engine (`FGenericApplicationMessageHandler` / Enhanced Input simulation).
- Exploration heuristic evaluated: NavMesh random-walk vs curiosity-driven exploration vs visual reinforcement agents.
- Automated anomaly detection criteria defined: zero-velocity stuck detection (stuck for >5 s), physics clipping/fall-through-floor detection (`position.y < kill_z`), shader error logs, and framerate drop tracking (<20 fps hitching).
- Bug report receipt format designed: timestamp, reproduction input stream, engine log trace, camera transform, and viewport screenshot.
