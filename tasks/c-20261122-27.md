## Goal
Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Design an automated, self-contained headless ComfyUI runtime manager inside KesherAI that isolates Python dependencies, automates snapshot rollbacks, and schedules diffusion jobs without user setup.

## Acceptance
- Architecture based on ComfyUI Desktop V1.2 principles: managing a relocatable embedded Python virtual environment with bundled PyTorch wheels and CUDA dependencies on secondary storage (drive E:).
- Headless WebSocket execution pipeline: dispatching procedural workflows (PBR texture baking, Trellis 3D generation, Wan 2.1 video expansion) via `/prompt` and monitoring status over `/ws` with step progress and cancellation.
- Dynamic VRAM coordination: forcing PyTorch garbage collection and VRAM release (`torch.cuda.empty_cache()`, `--gpu-only` vs `--lowvram` flags) immediately upon job completion to free memory for the local LLM.
- Snapshot rollback system: backing up custom node definitions and workflow schemas before automated updates to prevent broken graph dependencies.
