## Goal
Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Architect bi-directional Model Context Protocol (MCP) support in KesherAI: enabling KesherAI to act as an MCP Client to Unreal 5.8+'s native Unreal MCP server, while exposing KesherAI's headless tools as an MCP Server to external tools (Cursor, Claude Code).

## Acceptance
- Protocol analysis of Unreal Engine 5.8+ official `Unreal MCP` plugin: transport layer (JSON-RPC over HTTP/SSE vs stdio), tool registration schema, authentication, and supported operations (actors, Blueprints, PCG, Sequencer).
- Godot Engine MCP analysis: mapping community Godot MCP servers to KesherAI's native Godot bridge addon.
- Bi-directional architecture designed:
  1. KesherAI Agent as MCP Client: querying engine tools directly through MCP without custom bridge protocol maintenance.
  2. KesherAI Core as MCP Server: exposing KesherAI's offline scene reading, material translation, and asset indexing to Claude Code and Cursor.
- Conflict arbitration: handling concurrent edits between external MCP clients and KesherAI's local self-work agent.
