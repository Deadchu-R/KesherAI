## Goal
Roee (27.11): translation models should run on the processor, not the graphics card. Today the translator (packages/core/src/server/build-translator.ts, pickTranslator in translate.ts) prefers the loaded chat model, else a TranslateGemma GGUF in the "side" engine (side-engine.ts) with the GPU plan.
Change: a translator setting "Run on: processor (default) / graphics card / automatic". Processor = the TranslateGemma GGUF in its own small llama.cpp instance with `-ngl 0` (the way packages/core/src/server/build-watchdog.ts starts the CPU watchdog model: loaded on demand, stopped after its idle minutes), threads set to the physical cores minus 2. It never loads or swaps the big chat model just to translate. Automatic = processor for short texts (prompts, chat lines, under ~1,500 characters) and the graphics card only for long texts when the card is idle and no game runs (the game watch, packages/core/src/game-watch.ts). Show in Settings › model team which one translated last and how long it took. Hebrew+English texts, 390 px. Tests (node:test) for the choice (length, game running, setting).
