Build: (1) auto-update: when an update is available (packages/core/src/updates.ts) and no agent task, image/video job, chat stream or computer task is running for 2 minutes, install it; at most once per hour; send a phone notification 'KesherAI updated to X' (existing push path) and an error notification if it fails (the install-failed path exists).
