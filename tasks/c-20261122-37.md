## Goal
Always about KesherAI and its usability for Roee. First read docs/research/INDEX.md and don't repeat what is there. KesherAI's phone app reaches the PC through the Kesher Cloud hub (a Cloudflare Worker + Durable Object on the free plan). Today the hub hit Cloudflare's free daily storage limits and the phone could not reach the PC for hours. Roee wants a free backup path so he never has to wait: the phone app tries the hub first and falls back automatically.
Also compare a second, independent free relay on another provider as failover for the Cloudflare hub (e.g. Deno Deploy, Fly.io, Supabase Realtime, Firebase Realtime Database — each used within its own free terms), and prefer Tailscale Serve (tailnet only) over Funnel (public internet). Compare end to end, all free for one person: Tailscale (personal plan, Android app + Windows, MagicDNS, Funnel/Serve), Cloudflare Tunnel (cloudflared on the PC + Access with Google sign-in, free, no Durable Object storage), WebRTC peer-to-peer with the hub only for signalling (and STUN/TURN options that are free), ZeroTier, ngrok free, and how LM Studio (lms link over Tailscale), Home Assistant, Syncthing, Parsec/Moonlight do remote access. For each: setup effort for a non-network user (what Roee taps), security (who can reach the PC, end-to-end encryption, keys), limits of the free plan, battery/data on the phone, works from mobile networks and behind CGNAT, how KesherAI can automate the setup from its own app (one button), and how the phone app picks the path automatically.
To look at KesherAI's code (packages/core/src/hub-client.ts, apps/hub, the Android app in apps/android, packages/core remote/pairing), use your file tools or simple read-only commands.
