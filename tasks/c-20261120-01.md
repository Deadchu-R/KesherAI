## Goal
When an old tool output is shortened, the marker line says how much was cut, so the model knows what it is missing.

## Read first
packages/agent/src/context.ts: `shortenOldToolOutputs` (the marker text in the middle of the shortened output).

## Acceptance
- The marker becomes: `… [shortened: N lines / M characters cut; the full output is still in the conversation] …`
  where N and M count the removed middle part.
- The cut sizes (700 start, 500 end, 1500 threshold) and the moving line logic do not change.
- A test in packages/agent/src/context.test.ts (create it if missing, `node:test` + `node:assert/strict`) checks N and M
  for one long output, and that a short output is unchanged.
- `pnpm -s typecheck` passes.

## Out of scope
Any other file or function.

## Report
The new marker text and the test name.
