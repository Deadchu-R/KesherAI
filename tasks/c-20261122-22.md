## Goal
Always about KesherAI and its usability for Roee. To look at the code use your file tools or simple read-only commands.

Define the technical architecture for an ultra-low-latency local voice pipeline that transcribes bilingual Hebrew/English spoken commands and maps them into engine actions (C#, Blueprints, or editor commands).

## Acceptance
- Local Speech-to-Text (STT) runtime evaluated for bilingual speed: Whisper.cpp (large-v3-turbo vs base/small) vs Moonshine ONNX WebGPU, targeting <300 ms audio-to-text latency on local RTX 3090.
- Command classification schema: mapping spoken phrases in Hebrew (e.g., "תוסיף אור אדום מעל השחקן") and English ("Add a point light above the player") directly into KesherAI engine tools.
- Spoken feedback / TTS integration: evaluating lightweight local text-to-speech engines (Piper TTS, Chatterbox Multilingual, Kokoro-82M) for brief audio confirmation receipts.
- Background listening loop: push-to-talk vs voice-activity-detection (VAD via Silero VAD ONNX) with zero GPU idle consumption.

## Out of scope
Do not record microphone audio or run speech servers.
