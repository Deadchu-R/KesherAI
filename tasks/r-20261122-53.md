Add "Import research report" to the Task inbox page: a text area to paste the report or a .md/.txt file picker, a title, and an Import button. Reuse code; don't duplicate. Texts Hebrew and English (L(he,en)); 390px phone layout; works from the phone through the hub. Tests with node:test next to the code (parse + save path, size limit 200 KB, only docs/research written). Update docs/WORK_LIST.md.
