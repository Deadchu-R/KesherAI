## Goal
Roee: "in the hub and the app you can follow a task's steps, but it is not clear what each step means — write what the step is."
1. Add a pure function `describeStep(step, lang)` in a new file packages/shared/src/step-words.ts that turns one agent step (tool name + args + short result, as the task inbox stores them: see `decisions` / `InboxDecision.what` and the step data used by apps/web/src/StepsPanel.tsx and `agentDoing` / `stepTool` in apps/web/src/Helpers.tsx) into one short plain line with an icon, in Hebrew or English. Examples: read file → "📖 Read Logs.tsx (lines 1–120)" / "📖 קרא את Logs.tsx (שורות 1–120)"; edit/write → "✏️ Edited TaskInboxPage.tsx (+12 −3)"; run command → "▶️ Ran typecheck — 2 errors"; search/grep → "🔎 Searched the code for 'quickInstall'"; list dir → "📂 Listed apps/web/src"; web fetch → "🌐 Opened <host>"; unknown tool → "⚙️ <tool name>". Only the file's base name, never full paths with a user name. No model calls.
2. Use it wherever task steps are shown: the PC task page (apps/web/src/pages/TaskInboxPage.tsx and StepsPanel.tsx) and the phone hub's task view (apps/hub). Keep the raw step in a tooltip / folded "details".
3. node:test tests in packages/shared/src/step-words.test.ts for each kind and both languages.
4. Mark the WORK_LIST item "Readable task steps" ✅.
Readable, documented (JSDoc) code; 390px phone layout.
