# Research on Google Antigravity's Model Quota and Reset Time
Google Antigravity's model quota and reset time can be accessed locally through open-source "Antigravity quota" watchers/extensions. These extensions find the local language server process, its port, and CSRF token, then poll the HTTPS API endpoint to retrieve quota information. The response fields include per-model remainingFraction, resetTime, and weekly limit. This research aims to summarize the findings on how these extensions work and their compliance with Google's terms of service.

## Discovery Steps
The open-source extensions discover the local language server process by name, extract its CSRF token and extension port from its command-line arguments, and identify which TCP ports the process is listening on [1,2, 3]. The process name may vary depending on the platform, such as "language_server" on Windows and "language_server_macos" on macOS [7]. The extensions then verify that the process is the correct one by making an authenticated request to the HTTPS API endpoint [3].
