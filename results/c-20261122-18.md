## Summary
The research report has been documented in [c-20261122-18.md](file:///docs/research/c-20261122-18.md).

### Main Finding
Direct binary `.umap` parsing is brittle in UE5 because World Partition splits scene actors into thousands of loose external packages (`__ExternalActors__`), while running headless commandlets (`UnrealEditor-Cmd.exe`) introduces severe latency (25–90 s) and RAM pressure (2.5–8 GB). The optimal architecture is a three-tier hybrid: serve inspections instantly (<5 ms, <30 MB RAM) from lightweight pre-indexed JSON caches captured during editor shutdowns, fall back to fast filesystem `.umap` directory scanning (`scanContent`), and reserve headless commandlets for asynchronous background indexing and queued mutation write-backs.
