# Game Helper

Help while you play, from your own models (nothing leaves the computer), like Xbox's Gaming Copilot and NVIDIA's
G-Assist.

1. While a game is in front, press **Ctrl+Alt+G**. KesherAI takes one picture of the screen and opens a window on
   the right, over the game.
2. Press a question (or its controller button): **X** what to do here, **Y** what is on the screen, **RB** a guide
   from the web. Or type or speak your own question in the box below. The picture goes with the first question.
3. **B** or **Esc** (or Ctrl+Alt+G again) closes it, and the game is in front again.

Each game has its own chat (🎮 and the game's name in your chats), so the helper remembers earlier questions.
Answering about a picture needs a chat model that sees pictures (Models → 👁 on a local model, or a cloud model).

**On a ROG Ally / ROG Xbox Ally:** in Armoury Crate (Command Center → Control mode → Gamepad → Edit mappings), set a
back button (M1 or M2) to the keyboard keys Ctrl+Alt+G. On a Steam Deck: Steam → controller settings for the game →
a back grip button → keyboard Ctrl+Alt+G.

Windowed and borderless games show the window on top; an exclusive full-screen game hides it until Alt+Tab (switch
the game to borderless).
