# Game Helper

Help while you play, from your own models (nothing leaves the computer), like Xbox's Gaming Copilot and NVIDIA's
G-Assist.

1. While a game is in front, press **Ctrl+Alt+G**. KesherAI takes one picture of the screen and opens a window on
   the right, over the game.
2. Press a question (or its controller button): **X** what to do here, **Y** what is on the screen, **LB** graphics
   settings for this computer's card (from the web), **RB** a guide from the web. Or type or speak your own question in the box below. The picture goes with the first question.
3. **B** or **Esc** (or Ctrl+Alt+G again) closes it, and the game is in front again.

The top line shows the computer's load while you play (card use, temperature, memory, power; processor; RAM),
as NVIDIA's G-Assist overlay does.

Each game has its own chat (🎮 and the game's name in your chats), so the helper remembers earlier questions.
Answering about a picture needs a chat model that sees pictures (Models → 👁 on a local model, or a cloud model).

**On a ROG Ally / ROG Xbox Ally:** in Armoury Crate (Command Center → Control mode → Gamepad → Edit mappings), set a
back button (M1 or M2) to the keyboard keys Ctrl+Alt+G. On a Steam Deck: Steam → controller settings for the game →
a back grip button → keyboard Ctrl+Alt+G.

Windowed and borderless games show the window on top; an exclusive full-screen game hides it until Alt+Tab (switch
the game to borderless).

## The whole app with a controller

KesherAI itself works with a game controller (ROG Ally, an Xbox pad, a Steam Deck), like Steam Big Picture:

| Button | Does |
| --- | --- |
| D-pad or left stick | Move between buttons, links and fields |
| A | Press |
| B | Back: closes a menu or dialog, otherwise the previous page (in the Game Helper: closes it) |
| X | More options (right-click) |
| Y | Search and commands |
| LB / RB | Previous / next page of the menu |
| Menu (≡) | Open or close the side menu |
| View (⧉) | To the chat box |
| Right stick · LT / RT | Scroll · a page up / down |
| R3 (right stick pressed) | Microphone: speak the message; press again to finish |
| L3 (left stick pressed) | Stop the answer, or the reading aloud |

The controller look (a bold focus ring, button hints) shows only after the controller is used; mouse, touch and
keyboard work as before. **ROG Ally in Desktop mode** (the controller acts as a mouse and keyboard): arrows move,
Enter presses, Esc goes back.
