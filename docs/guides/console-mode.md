# Console mode

**עברית בקצרה:** מסך בית מלא עם כפתורים גדולים לשליטה בגיימפד, למכשירי כף יד כמו ROG Xbox Ally X, וגם עוזר משחק. ברגע שמזוהה כף יד מוצע המצב פעם אחת; אפשר להפעיל ולכבות בהחזקת View+Menu. **עוד לא גמור:** כפתורים גדולים ועוזר משחק נבנים כעת.

## What it does
A full-screen home with no menus, made for a controller on a handheld or a TV, with controller hints and an on-screen keyboard.

## Prerequisites
A gamepad (or a handheld's built-in one) and KesherAI on that device or reached through remote access.

## Steps
1. Connect the controller. When a handheld is found, KesherAI offers console mode once; accept.
2. Or hold **View + Menu** to turn it on. Its own page turns it off.
3. Move with the stick or D-pad, confirm and go back with the face buttons; hints show the buttons.
4. The game helper window opens over a game (see [../GAME_HELPER.md](../GAME_HELPER.md)).

## Verify
Navigate the home screen with the pad only.

## Troubleshooting
- Not offered: the pad was not detected; press a button once so the browser sees it.
- Hold gesture ignored: it is off inside the Game Helper's window over a game.

## Safety
Same approvals as any chat; nothing is auto-approved by the controller.
