## 1. Industry Context & What Moved in the AI Landscape (2025–2026)

### 1.1 Local Model Runtimes & Quantization Economics
The viability of local autonomous coding agents on consumer workstation hardware has advanced significantly:
* **The 24 GB VRAM Envelope on Nvidia RTX 3090 / 4090:** Models such as `Qwen2.5-Coder-32B-Instruct` [8] and `DeepSeek-R1-Distill-Qwen-32B` have established that 32B-parameter models achieve code reasoning on par with proprietary cloud models (approaching Claude 3.5 Sonnet on SWE-Bench Verified). In standard 4-bit quantization (`Q4_K_M`), the model weights occupy ~18.5 GB to 19.5 GB of VRAM [8]. This leaves 4.5 GB to 5.5 GB of headroom on a 24 GB card.
* **KV Cache and Flash Attention Pressures:** In long-context coding sessions (16K–32K tokens), standard 16-bit float KV caches require 4 GB to 8 GB, causing immediate Out-Of-Memory (OOM) failures or swapping to system RAM [13]. The integration of Flash Attention (`--flash-attn`) alongside 4-bit/8-bit KV cache quantization (`--cache-type-k q4_0 --cache-type-v q4_0`) in `llama.cpp` reduces KV cache overhead by up to 60%, maintaining inference speeds of 25–33 tokens per second (`t/s`) on single RTX 3090 setups [13].
* **Prompt Caching and Multi-Slot Reuse:** `llama.cpp`'s slot management (`--slot-save`, `--prompt-cache`) eliminates prompt-reprocessing penalties for static prefixes (system instructions and tool signatures), reducing per-turn latency from 4–8 seconds down to sub-500 ms [13].

### 1.2 Game Engine AI Tooling: The Model Context Protocol (MCP) Shift
* **Unreal Engine 5.8+ Official MCP:** Epic Games introduced experimental first-party Model Context Protocol (MCP) support in Unreal Engine 5.8 [4], complemented by open-source community bridges [5]. Instead of relying on isolated chat docks, the Unreal MCP server exposes engine reflection (`ClassDB`, actor transformation, Blueprint node graph compilation, sequencer automation, and PIE automation) directly over JSON-RPC [4, 5]. External agents (Claude Code, Cursor, KesherAI) can manipulate engine state directly through standard tool calls [4].
* **Godot 4 Ecosystem Acceleration:** Unlike commercial engines, Godot excludes built-in AI vendors from its core [3]. In response, the community standardized around Godot MCP bridges (`Godot AI`, `GDAI MCP`, `Godot-MCP-Toolkit`) [3]. Godot’s human-readable text scenes (`.tscn`), modular resource system (`.tres`), and lightweight headless binary (`godot --headless`) allow external AI agents to instantiate scenes, validate node paths, and execute automated GDScript unit tests in sub-second times without opening a graphical window [3].
* **Unity AI Assistant Consolidation:** Unity streamlined its fragmented "Unity Muse" suite (Muse Chat, Sprite, Texture, Animate, Behavior) into the unified "Unity AI Assistant" for Unity 6, backed by the Sentis neural runtime for on-device ONNX execution [2].

### 1.3 Creative Media & Video Foundation Models
* **ComfyUI Desktop API Standard:** ComfyUI launched its official standalone Desktop application, establishing `workflow_api.json` as the de facto programmatic interface for generative pipelines [6]. By enabling Dev Mode, developers extract lightweight, UI-agnostic execution graphs that run headlessly via local WebSocket and HTTP endpoints (`http://127.0.0.1:8188/prompt`), streaming per-node progress and preview frames directly into external clients [6].
* **Wan 2.1 Local Video Generation:** Alibaba's open-weights Wan 2.1 video foundation model suite released in early 2025 [7]. The lightweight Wan 2.1 1.3B variant operates within an 8 GB to 12 GB VRAM footprint, enabling consumer GPUs (RTX 3090, 4070, 4080) to synthesize 5-second 720p cinematic video clips locally [7]. The larger Wan 2.1 14B model provides state-of-the-art motion coherence and temporal stability, though it demands 4-bit GGUF quantization or multi-GPU offloading [7].

### 1.4 Agentic Coding Paradigms: Cursor vs. Windsurf vs. Claude Code
The industry has split into three distinct agentic interaction architectures [10, 11, 12]:
1. **Cursor (Composer / Agent Mode):** Focuses on continuous background codebase indexing, asynchronous dependency graph queries, and non-modal inline ghost diffs (`Cursor Tab`) [10].
2. **Windsurf (Cascade):** Employs an ephemeral memory loop with explicit multi-step planning modes that decompose complex refactoring tasks into milestone verification checkpoints before committing edits [11].
3. **Anthropic Claude Code CLI:** Rejects GUI confines entirely, operating as a headless terminal agent loop [12]. Claude Code interacts natively with shell environments, coordinates Git worktrees for isolated agent execution, prunes context dynamically, and orchestrates specialized subagents via MCP tools [12].

### Task NEW-9: Two-Way Model Context Protocol (MCP) Host and Reverse Bridge for KesherAI
* **Why We Are Missing It:** KesherAI currently implements an MCP server export for Claude (`packages/core/src/mcp-server.ts`), allowing Claude to call KesherAI. However, KesherAI **cannot consume external MCP servers as a client/host**. As demonstrated by LM Studio 0.3.17+ [1] and 0.4.0 [1], native MCP Host capabilities allow any local model to dynamically access third-party tools (GitHub, PostgreSQL, Brave Search, Blender MCP, Godot MCP, Unreal MCP) configured via a standard `mcp.json` file [1, 2]. Furthermore, a "Reverse MCP" bridge allows external IDEs like Cursor and VS Code to use KesherAI's local model engines for offline code completion [1].
* **Value to Roee:** Unlocks thousands of community MCP tools for KesherAI's chat and local agents, while simultaneously allowing Roee's primary IDE (Cursor / VS Code) to use KesherAI as its unified local tool provider.

### Task NEW-10: Speculative Next-Edit Suggestions (NES) & Ghost Diffs via Small Local Draft Models
* **Why We Are Missing It:** Modern AI code editors (Cursor Tab [10] and Windsurf Cascade [11]) have evolved past reactive chat into **predictive next-action completion** [10, 11]. When a developer edits a function signature, the editor proactively predicts the *subsequent edit location* (e.g., updating caller sites or unit tests) and presents an inline "ghost diff" that is accepted with a single `Tab` keypress [10]. KesherAI has `span-edit.ts` and `chat-queue.ts`, but lacks predictive next-edit speculative drafting.
* **Value to Roee:** Eliminates prompt typing for repetitive refactors. When editing C# scripts in Unity or TypeScript in KesherAI, pressing Tab instantly applies the logical next edit.

### Task NEW-11: Local Procedural Game SFX & Foley Generation via AudioLDM2 and Stable Audio Open
* **Why We Are Missing It:** KesherAI currently provides `make_sound` and ACE-Step music generation, but game developers require **sound effects (SFX) and foley audio**: footstep variations, UI clicks, weapon impacts, magic whooshes, and atmospheric ambient loops. In game engines, sounds must be trimmed to exact transients, normalized, and exported as mono/stereo WAV files or MetaSound asset templates.
