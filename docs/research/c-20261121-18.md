## ## Recommended Structure for an All-in-One Multi-Modal App
For an advanced application housing chat, multi-modal editors (image, video, sound, 3D), game-engine tools, models, and agents, the following structure is recommended based on modern AI UX trends:

1. **Global Layout & Navigation (Unified Sidebar)**
   * **Collapsible Left Sidebar:** Contains a unified menu split logically into sections: *Recent Chats / Projects*, *Active Agents*, and *Model Selector*.
   * **Bottom Utility Dock:** Houses user profile, system settings, and theme toggles (Light/Dark mode switch).

2. **Color-Coded Functional Zones**
   * To prevent cognitive overload in a feature-rich environment, apply subtle, semantic color-coding to workspace headers or accent borders:
     * *Chat & Agents:* Neutral / Brand Accent (e.g., Classic Blue/Indigo)
     * *Visual Editors (Image/Video):* Creative Accent (e.g., Purple/Magenta tint)
     * *Audio & 3D Environments:* Spatial Accent (e.g., Teal/Cyan tint)
     * *Game-Engine & Models:* Engineering Accent (e.g., Amber/Orange tint)

3. **Light Theme Optimization**
   * Provide a pristine, high-contrast **Light Theme** utilizing off-white/light-gray background surfaces (`#F8F9FA`) with dark gray typography (`#212529`) to reduce eye strain, paired with distinct card surfaces (`#FFFFFF`) for editors and timelines.

4. **Contextual Workspace Switching (Desktop)**
   * **Center Stage:** Dynamically adapts based on the active mode selected in the unified menu. Selecting an asset editor opens a multi-pane layout (viewport, timeline, parameter inspector), while selecting chat opens a clean conversational thread.

5. **Mobile Adaptation**
   * **Bottom Navigation Bar:** For phone versions, shift primary high-level navigation (Chat, Editors, Agents, Settings) to a thumb-friendly bottom tab bar.
   * **Full-Screen Modals:** Open heavy editors (3D/Video) into dedicated full-screen views with simplified floating toolbars to preserve usability on smaller screens.

6. **RTL (Hebrew) Implementation**
   * Full mirroring of the layout: the sidebar moves to the right, iconography flips where directional, and text alignment defaults to right-to-left while preserving left-aligned code blocks or numerical parameters.
