## W3C Design Token Extraction via Figma REST API

Design tokens—including typography, color palettes, border radius, and 9-slice sprite parameters—are extracted using the Figma Variables REST API (specifically `/v1/files/:id/variables/local`), adhering strictly to the W3C Design Tokens / DTCG JSON format [9, 11, 14].

* **Extracted Types:**
  * **Color:** Mapped from Figma variable color values to DTCG-compliant `#hex` strings [9].
  * **Dimension (Number/Float):** Mapped to pixel values (e.g., spacing and border radii represented as `Npx`) [9].
  * **Typography:** Extracted as font families, weights, and sizes [9, 13].
* **Standards Compliance:** Tools and plugins export variables grouped by modes into standard `.json` files compatible with downstream style dictionary workflows [11, 14]. (Note: The Figma Variables REST API requires Enterprise plans, while free tiers rely on plugin-based extraction approaches) [9, 16].

## Asset Export Pipeline for Textures and SVGs

The asset export pipeline handles fetching vector SVGs and raster textures directly via the Figma REST API, routing them into target project directories (`Assets/UI` for Unity or `Content/UI` for Unreal) [4].

* **Directory Routing & Import Settings:** Assets are automatically deposited into designated engine folders [4]. For Unity, imported raster textures are configured with `Sprite 2D` or `Texture2D` import settings, while vector graphics are handled as clean UI assets.
* **9-Slice Sprite Parameters:** Slice parameters for scalable UI elements are calculated from frame bounds and exported alongside visual assets to ensure proper scaling behavior in both UI Toolkit and UMG brushes.

## Offline Bridge and Headless Code Generation

To support automated workflows for KesherAI without opening engine editors or generating binary `.uasset` files, deterministic offline scripts generate code structures directly [7].

* **Deterministic Scripts:** Python or C# scripts parse intermediate representation (IR) layout files and JSON design tokens to output text-based engine structures (such as Unity `UXML`/`USS` files or text-serialized Unreal structures) headlessly [4, 7].
* **Pipeline Integration:** Utilizing tools like `figma-token-extractor` and intermediate protocol compilers allows Roee to run validation checks and build UI trees locally or via automated build agents prior to opening the game editor [4, 9].

## Conclusion

Automating the translation of Figma designs to Unreal UMG and Unity UI Toolkit bridges the gap between design and implementation [3, 4]. By standardizing layout mapping on flexbox and panel hierarchies, extracting design tokens into W3C-compliant DTCG JSON files, systematically handling asset routing, and executing headless offline generation via deterministic scripts, KesherAI achieves a robust, repeatable, and scalable UI pipeline for Roee without relying on manual entry or live editor dependencies [1, 4, 7, 9].
