# Fastest Local Engine and Settings for KesherAI Users
KesherAI is a local-first AI desktop app that supports various platforms, including Windows, macOS, and Linux, with different GPU architectures such as NVIDIA, AMD, Intel, and Apple Silicon. The fastest local engine and settings for KesherAI users depend on the platform and hardware used. 

## Windows with NVIDIA GPU
On Windows with NVIDIA GPU, the fastest local AI engine is llama.cpp with CUDA [1], which provides a simple local model service and a lightweight C/C++ runtime. TensorRT is also a suitable option for developers who want to optimize and deploy AI models with maximum control and best performance on NVIDIA GPUs [2]. 

## macOS with Apple Silicon GPU
On macOS with Apple Silicon GPU, MLX-LM is the fastest inference engine, providing peak Apple-optimized throughput [9]. However, llama.cpp is also a viable option, offering flexibility, faster feature adoption, and broader model support, although it is about 20-30% slower than MLX-LM [9].
