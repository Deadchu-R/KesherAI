# KesherAI

**בית אחד, לוקאלי קודם, לכל סוג של מודל AI — צ'אט, קוד, תמונות, וידאו וסאונד — שרצים על המחשב שלך ועובדים יחד.**

[English](README.md) · [חזון (באנגלית)](docs/VISION.md) · [ארכיטקטורה](docs/ARCHITECTURE.md) · [תוספים](docs/PLUGINS.md) · [API](docs/API.md)

> **סטטוס: מוקדם (v0.1).** צ'אט, מוריד המודלים, יצירת תמונות דרך ComfyUI, ה-API התואם OpenAI, גישה מרחוק, סקילים ותוספים עובדים. סוכן הקוד, MCP, וידאו, סאונד ו-Pipelines בדרך.

הדוקומנטציה הראשית של הפרויקט כתובה באנגלית, כדי שכל מפתח בעולם יוכל לתרום. הקובץ הזה הוא תרגום של ה-README.

## למה

היום, להריץ AI לוקאלית אומר לעבוד עם LM Studio לצ'אט, ComfyUI לתמונות, כלי אחר לדיבור ו-CLI לסוכני קוד — לכל אחד תיקיית מודלים משלו, ממשק משלו, ואין דרך להעביר עבודה ביניהם. KesherAI ("קשר") מחבר את כולם:

- **לוקאלי קודם.** הכל עובד בלי אינטרנט ובלי חשבון. ענן הוא תוסף, לא תנאי.
- **מחבר, לא ממציא מחדש.** KesherAI מפעיל מנועים מוכחים — llama.cpp, ComfyUI, Ollama, LM Studio, OpenCode — במקום לכתוב אותם מחדש. כבר משתמש באחד מהם? חבר אותו כשרת.
- **כל מודל בקטגוריה שלו.** צ'אט, תמונה, וידאו, דיבור לטקסט, טקסט לדיבור, מוזיקה, embeddings, תלת-ממד — ותוספים יכולים להוסיף עוד.
- **שרת אחד, הרבה לקוחות.** הליבה רצה כשרת לוקאלי. חלון הדסקטופ, הטלפון וכל כלי תואם OpenAI הם לקוחות שלו.
- **פתוח לכולם.** Apache-2.0, קוד מתועד, API לתוספים, ומבנה שמתוכנן לפורקים.

## התחלה מהירה

דרישות: **Node.js 22+** ו-**pnpm 10+** (`corepack enable`).

<div dir="ltr">

```bash
git clone https://github.com/Deadchu-R/KesherAI.git
cd KesherAI
pnpm install
pnpm build:packages
pnpm dev            # שרת ליבה ב-7420 + ממשק ב-http://localhost:5173
```

</div>

אחר כך פתח את מסך **חיבורים**. אם LM Studio, Ollama או ComfyUI רצים, KesherAI כבר מצא אותם. אחרת הוסף API בענן, או היכנס ל**מודלים והורדות**, הורד מודל GGUF ולחץ **טען ב-llama.cpp**.

## שימוש מהטלפון

הפעל `"remote": { "enabled": true }` בקובץ `~/.kesher/config.json` והפעל מחדש. מחוץ לרשת הביתית השתמש ב-Tailscale או WireGuard, ואל תחשוף את הפורט לאינטרנט. פרטים ב-[SECURITY.md](SECURITY.md).
